# Diamond Farm (Fabric, Minecraft 26.2, Java 25)

Build jar:
  Windows: gradlew.bat build   (atau: gradle build)
  Linux/Mac: ./gradlew build   (atau: gradle build)
Hasil: build/libs/diamondfarm-1.0.0.jar  (jangan ambil yang -sources)
Taruh di folder mods bersama Fabric API 0.161.0+26.2.

Cara main:
- Craft: 1 Diamond + 3 Wheat Seeds -> 3 Diamond Seeds
- Tanam di farmland, tunggu age 7 (stage penuh), panen -> 1-2 Diamond + 0-2 Diamond Seeds
